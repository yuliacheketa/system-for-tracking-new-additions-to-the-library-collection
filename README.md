# System for Tracking New Additions to the Library Collection

Система обліку нових надходжень до бібліотечного фонду: реєстрація, каталогізація та перегляд щойно доданих видань.

## Короткий опис

Проєкт допомагає бібліотеці фіксувати нові книги та матеріали в одному місці — від моменту надходження до появи в каталозі. Користувачі можуть додавати записи, оновлювати статуси обробки та переглядати список нових надходжень.

## Потенційні ролі

| Роль | Можливості |
| --- | --- |
| **Administrator** | Керує користувачами, довідниками та налаштуваннями системи |
| **Librarian** | Додає й редагує нові надходження, веде каталожні записи |
| **Acquisitions Officer** | Фіксує закупівлі / дари, статуси отримання та передачі в обробку |
| **Cataloger** | Уточнює бібліографічні дані, класифікацію, готовність до видачі |
| **Reader (Guest)** | Переглядає публічний список нових надходжень без права редагування |
