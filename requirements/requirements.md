# Вимоги до системи

Проєкт: System for Tracking New Additions to the Library Collection  
(облік нових надходжень до бібліотечного фонду)

Нижче зібрані основні вимоги, які потрібні для першої версії системи.

## Функціональні вимоги

**ФВ-1.** Система має дозволяти додавати нове надходження (книга або інший матеріал) з базовими полями: назва, автор, рік, тип надходження (закупівля / дар), дата отримання.

**ФВ-2.** Користувач з відповідною роллю може змінювати статус обробки надходження, наприклад: отримано → в обробці → каталогізовано → готово до видачі.

**ФВ-3.** Каталогізатор може уточнювати бібліографічні дані вже створеного запису (класифікація, опис, примітки) без створення дубліката.

**ФВ-4.** Гість (читач без облікового запису для редагування) може переглядати публічний список нових надходжень, які вже готові або нещодавно додані.

**ФВ-5.** Адміністратор може керувати користувачами системи: створювати облікові записи, призначати ролі та блокувати доступ при потребі.

## Нефункціональні вимоги

**НФВ-1.** Інтерфейс має бути зрозумілим для бібліотечних працівників без довгого навчання — основні дії (додати, змінити статус, знайти запис) мають бути помітні з першого екрана.

**НФВ-2.** Доступ до редагування обмежений за ролями. Гість не може змінювати записи; звичайний бібліотекар не керує користувачами.

**НФВ-3.** Базові сторінки (список надходжень, форма додавання) мають відкриватися прийнятно швидко при звичайному навантаженні бібліотеки (орієнтовно до 2–3 секунд).

**НФВ-4.** Дані про надходження не мають губитися при збої на клієнті: після збереження запис залишається в системі і доступний після повторного входу.

**НФВ-5.** Система має коректно працювати в актуальних версіях Chrome і Firefox (десктоп). Адаптація під мобільні — бажана, але не пріоритет першої версії.
